Suche

  • Mehrere Begriffe werden kombiniert: „Flur lux“ zeigt nur die passenden Tabellenzeilen. Über „alle Zeilen zeigen“ erscheint die vollständige Tabelle.
  • Umlaute sind egal (buero = Büro), gängige Synonyme werden mitgesucht (Klassenzimmer → Unterrichtsraum, WC → Toilette/Sanitär, Lux → Beleuchtung, GEG → GModG).
  • Taste / springt in das Suchfeld, Esc leert es. Die Adresse enthält die Suche (#q=…) und kann als Link weitergegeben werden.
  • ★ merkt Themen als Favoriten in diesem Browser. „Tabelle kopieren“ liefert tabulatorgetrennten Text für Excel oder Word.

Stand und Gewähr
